# Marc Humphrey Portfolio

Personal portfolio for Marc Humphrey, a Computer Science graduate of Saint Joseph's University pursuing an M.S. in Cybersecurity. It covers projects, client work, experience, and a downloadable résumé.

## Stack

React, Vite, Tailwind CSS, Framer Motion, React Router, tsParticles

## Run locally

```
npm install
npm run dev
```

## Deploy

Deployed on Vercel. Every push to `main` builds and publishes automatically.
